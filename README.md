# BA-Feld-Companion 🧭

A **business analyst consulting tool** that brings the core BA workflow into one place — from capturing stakeholders to managing requirements — built for real-world BA engagements.

## ✨ Features

- **Stakeholder register** — track who's involved and their role and influence
- **Interview capture** — record and organize stakeholder interviews
- **Pain point repository** — collect and prioritize business problems
- **Process mapping** — document how work flows today
- **Requirements management** — capture, organize, and track requirements
- **Consulting dashboard** — see the whole engagement at a glance

## 🧰 Built with

- **HTML** — structure
- **CSS** — styling and layout
- **JavaScript** — interactivity and data handling

## 🚀 Run it locally

1. Clone or download this repository
2. Open `index.html` in any web browser

No installation or setup needed — it runs right in the browser.

## 💡 About this project

I built this to mirror the real tools and artifacts a business analyst uses during a consulting engagement — turning the BA process into a single, practical companion app. It reflects both my BA knowledge and my growing front-end skills.
